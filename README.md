# Linked List in C

## Beschreibung

Dieses Projekt implementiert eine einfach verkettete Liste (Linked List) in der Programmiersprache C.

Die Liste besteht aus Knoten. Jeder Knoten speichert einen `double`-Wert und einen Zeiger auf den nächsten Knoten.

## Dateien

- `main.c` – Hauptprogramm zum Testen der Linked List
- `ll.c` – Implementierung der Linked-List-Funktionen
- `ll.h` – Definitionen und Funktionsdeklarationen der Linked List
- `CMakeLists.txt` – Konfiguration für den Build mit CMake

## Projektordner

Der Ordner `.idea` enthält Einstellungen von JetBrains CLion.

Der Ordner `cmake-build-debug` enthält die von CLion erzeugten Build-Dateien.

## Voraussetzungen

- C-Compiler, z. B. GCC
- CMake
- JetBrains CLion (optional)

## Kompilieren

Das Projekt kann in CLion mit CMake kompiliert und ausgeführt werden.

## Verwendung

Das Hauptprogramm befindet sich in `main.c`. Dort können die Funktionen der Linked List aufgerufen und getestet werden.
